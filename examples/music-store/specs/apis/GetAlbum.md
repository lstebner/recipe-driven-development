## Purpose
Fetch one album for its detail page.

## Auth
Public. Signed-in callers also get `owned`.

## Request
| field | type | required | notes |
|---|---|---|---|
| id | uuid | yes | path |

## Response
200: [[model:Album]] plus `owned: boolean` (always false when signed out)

## Errors
| code | status | when |
|---|---|---|
| not_found | 404 | no album with that id, or it's unlisted |

## Rules
- R1: An unlisted album returns not_found, never 403, so its existence isn't revealed.
- R2: `owned` is true exactly when [[policy:CanBuyAlbum]] gives `owned` for the caller.
