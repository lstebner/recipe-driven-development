## Purpose
Buy an album.

## Auth
Signed-in listeners only; anyone else gets 401.

## Request
| field | type | required | notes |
|---|---|---|---|
| albumId | uuid | yes | [[model:Album#id]] |
| paymentToken | string | yes | from the payment provider's card form |

## Response
201: the order id and the album's [[model:Album#id]]

## Errors
| code | status | when |
|---|---|---|
| not_found | 404 | no album with that id, or [[policy:CanBuyAlbum]] gives `unavailable` |
| already_owned | 409 | [[policy:CanBuyAlbum]] gives `owned` |
| card_declined | 402 | the payment provider declined the card |

## Rules
- R1: Charges [[model:Album#priceCents]] as it is when the order is created, not a price the client sends.
- R2: Two requests with the same paymentToken create at most one order.
- R3: An order is created only when [[policy:CanBuyAlbum]] gives `buy`, checked on the server when the request arrives.
