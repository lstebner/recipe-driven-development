# Design tokens

Reference these as `$name` in specs (e.g. `$color.accent`). Add a token here before using it.

## Color
| token | value | use |
|---|---|---|
| color.accent | #e4572e | calls to action |
| color.text | #1d1d1f | body text |
| color.muted | #6e6e73 | secondary text |

## Space
| token | value | use |
|---|---|---|
| space.md | 16px | default gap |
| space.lg | 32px | between major regions |

## Type
| token | value | use |
|---|---|---|
| type.heading | 24px / 600 | titles and prices |
| type.body | 16px / 400 | everything else |

## Radius & shadow
| token | value | use |
|---|---|---|
| radius.md | 8px | cards, artwork, buttons |
| shadow.card | 0 2px 8px rgb(0 0 0 / 0.12) | raised surfaces |
